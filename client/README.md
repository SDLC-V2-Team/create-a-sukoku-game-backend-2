# Sudoku Game - Web Client

This is the frontend client for the Sudoku game application.
It provides a user interface to start a new game and display the generated puzzle.

## Tech Stack
- React 18 with TypeScript
- Vite for build tooling
- Vanilla CSS for styling

## Setup
```bash
npm install
npm run dev
```

The development server runs on port 3000 and proxies `/api` requests to `http://localhost:5000`.

## Build for Production
```bash
npm run build
```
